## Overview

Secreto TV Cleaner helps you examine applications through a user-authorized Android Debug Bridge (ADB) connection and selectively force-stop eligible apps on Android TV and Google TV. It is an **app-management utility**, not an antivirus or an automatic performance booster.

## Features

- Choose between legacy ADB and supported wireless-debugging connection methods.
- Scan running processes and view installed applications.
- Identify apps eligible for safer force-stop actions; distinguish sensitive apps and protect core services.
- Select individual eligible applications or use the available bulk-stop action.
- Navigate with a TV remote; English, French and Arabic interfaces.
- No root access required.

## Safety and compatibility

- Enable ADB only on devices you own or are authorized to manage, ideally over a trusted local network. Disable debugging when it is no longer needed.
- Force-stopping an app can interrupt playback or background work. Android may restart applications later.
- Eligibility filters reduce risk but cannot guarantee that every force-stop is harmless. Review the app before stopping it.
- Availability and behavior depend on device firmware, Android version and ADB permissions. Some devices require additional setup.
- This app does not promise cache removal, RAM cleaning, malware protection or measurable speed gains.
